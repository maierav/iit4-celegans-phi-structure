Reading guide & honest limits. The simulation uses class-conditioned TPMs (attractant / repellent / control; per-chemical TPMs are undersampled at ~960 transitions), so two chemicals of the same class produce the same simulation but different real overlays — the gap between them is within-class chemical identity, which the TPM cannot carry. The chain is first-order Markov: it reaches the conditioned distribution within a few lags and stays flat, so it reproduces stimulus-locked level shifts (validated: all 4 sensory-neuron shifts match the data in sign, r ≈ 0.4–0.5) but not response latency or adaptation. The core quartet responds mostly after stimulus offset in the real data — a lagged effect the one-step TPM largely misses (r ≈ 0.1). Edges shown are observational effective sensitivity and can include common drive.
